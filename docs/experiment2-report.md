## 4. 手写时域四件套

对每个窗口分别计算三轴与合矢量特征（`window_features.csv`）：

- **均值** `mean = (1/N) Σ xᵢ`，主要反映重力与姿态；
- **方差** `var = (1/N) Σ (xᵢ − mean)²`（总体方差，`ddof = 0`），反映波动强度；
- **过零率**：去均值后统计符号变化次数，`ZCR = 过零次数 / 时长`，可选 FFT 带限处理；
- **峰值**：`peak_dynamic = max|xᵢ − mean|`，并同时保留 `peak_raw`。

合矢量方差统计：`min = 3.760`、`median = 6.548`、`max = 11.278`；全段动态峰值最大 9.169 m/s²。
特征分工结论：**方差**用于“动没动”，**ZCR / 主峰**用于“动多快”，**峰值**用于“动多大”。
对应图：`figures/time_features.png`。

## 5. FFT 主峰与步频

- 对每个窗口先去除直流分量，加汉宁窗，计算单边频谱并在 `0 ~ fs/2` 内查找主峰；
- 频率分辨率 `Δf = fs / N = 1 / W`，本报告 `W = 4 s` 时 `Δf = 0.25 Hz`；
- 步频换算：`step_frequency_spm = f_peak × 60`。

结果：284 个窗口的主峰全部落在行人步频带 `0.5 ~ 3 Hz` 内，步频中位数 **120.0 步/分**
（P05 = 105.0，P95 = 120.0）。代表窗口：

## 6. D06 参数实验场

| 窗长 W / s | 方差均值 | 方差标准差 | ZCR 均值 | 动态峰值均值 |
|---:|---:|---:|---:|---:|
| 0.25 | 4.141 | 2.404 | 7.754 | 3.692 |
| 0.5 | 6.640 | 1.912 | 5.674 | 4.937 |
| 1.0 | 6.670 | 1.484 | 5.723 | 5.443 |
| 2.0 | 6.705 | 1.232 | 5.788 | 5.919 |
| 4.0 | 6.738 | 1.014 | 5.793 | 6.592 |
| 8.0 | 6.751 | 0.702 | 5.795 | 7.095 |
| 16.0 | 6.721 | 0.662 | 5.750 | 7.884 |

结论：窗长越短，方差与 ZCR 的抖动越大、噪声越被放大；窗长越长，方差被平均钝化，
动态峰值反而更容易被大冲击抬高。

**短事件跨缝实验**（`d06_event_split.csv`）：把一个 1.2 s 短事件放在 t = 6.0 s，使 `S = W`
的窗口边界正好穿过事件：

| 窗长 W / s | S = W 最大覆盖率 | S = W/2 最大覆盖率 |
|---:|---:|---:|
| 1.0 | 0.50 | 0.83 |
| 1.5 | 0.50 | 1.00 |
| 2.0 | 0.50 | 1.00 |
| 3.0 | 0.50 | 1.00 |

结论：`S = W`（不重叠）会把短事件劈成两半，单窗最多只覆盖约一半能量；`S = W/2`（50% 重叠）
会有一个窗口完整覆盖事件，验证讲义推荐的工作点。

## 7. D07 混叠实验

真值信号 `2.8 Hz`，采样率依次取 `50 / 5 / 3 / 2 Hz`（`d07_summary.json`、`figures/d07_alias.png`）：

| fs / Hz | Nyquist / Hz | 谱主峰 / Hz | 标准折叠 / Hz | 关于 fs 的镜像 / Hz |
|---:|---:|---:|---:|---:|
| 50 | 25.0 | 2.80 | 2.80 | 47.20 |
| 5 | 2.5 | 2.20 | 2.20 | 2.80 |
| 3 | 1.5 | 0.20 | 0.20 | 2.80 |
| 2 | 1.0 | 0.80 | 0.80 | **1.20** |

失效链（现象 → 指标 → 谱 → 采样率）：

1. **现象**：真实快走约 2.8 Hz 被低采样率记录后，计步结果少算约一半；
2. **指标**：主峰频率从 2.8 Hz 折返到 0.8 Hz；
3. **谱**：单边频谱在混叠频率处出现假峰，而真实 2.8 Hz 已无法分辨；
4. **采样率**：`fs = 2 Hz` 低于 `2 × 2.8 = 5.6 Hz`，违反奈奎斯特定理。

关于 `1.2 Hz`：标准奈奎斯特折叠把 `2.8 Hz @ fs = 2 Hz` 折到 `0.8 Hz`；
课程页面给出的 `1.2 Hz` 是 `0.8 Hz` 关于采样频率的镜像（`2 − 0.8 = 1.2`）。
本实验同时输出两者以便对照，并在报告中明确区别，避免把镜像值当成带内混叠频率。

## 8. 作业②：公交防误计步

提出两个**可计算、可验证**的特征：

1. **步频带能量占比**：`R = P(0.5~3 Hz) / P(0.5~10 Hz)`；
2. **峰间隔变异系数**：`CV = std(步间隔) / mean(步间隔)`。

阈值思路：`R ≥ 0.5` 且 `CV ≤ 0.35` 判为步行。

| 数据 | 窗口数 | R 中位数 | CV 均值 | 判为步行的比例 |
|---|---:|---:|---:|---:|
| 真实步行（本人采集） | 284 | 0.860 | 0.059 | 100.00% |
| 车辆振动参考（仿真占位） | 39 | 0.019 | 0.288 | 0.00% |

**为什么不能只用“加速度大 / 方差大”**：把车辆整体振动做成方差接近甚至超过步行的信号后，
只用方差判定的基线把 **100%** 的乘车窗口误判为步行；而 R + CV 双特征把乘车误判率降到 **0%**。
原因是车辆振动能量集中在高频段且峰间隔杂乱，而步行能量集中在步频带且节奏稳定。

> 重要限制：当前乘车段使用**仿真车辆振动参考信号**验证特征管道；真实乘车特征必须在
> 20 分钟路线数据包含乘车站段后重新计算并标定阈值。相关图：`figures/bus_features.png`。
