## 1. Kwapisz, Weiss & Moore (2011)：手机加速度计的活动识别

> J. R. Kwapisz, G. M. Weiss, S. A. Moore. *Activity recognition using cell phone
> accelerometers.* ACM SIGKDD Explorations Newsletter, 12(2): 74–82, 2011.
> DOI: [10.1145/1964897.1964918](https://doi.org/10.1145/1964897.1964918)

### 1.1 方法框架

| 环节 | 做法 |
|---|---|
| 数据采集 | 29 名志愿者，Android 手机放在**前裤袋**；每 50 ms 采一次，即 **20 Hz** |
| 活动类别 | 走、跑、**上楼梯**、**下楼梯**、坐、站，共 6 类 |
| 分段 | 每 **10 s** 一段（段内 200 个点），称为 example duration；选择依据是"要容纳若干次重复动作" |
| 特征 | 共 **43 个**特征，来自 6 类基础特征：Average[3]、**Standard Deviation[3]**、Average Absolute Difference[3]、Average Resultant Acceleration[1]、**Time Between Peaks[3]**、**Binned Distribution[30]** |
| 分类器 | WEKA 的 J48 决策树、逻辑回归、多层感知机（MLP），均用默认参数 |
| 评价方式 | **10 折交叉验证**；并给出 "straw man" 基线（永远预测某一类）来衡量类别不平衡的影响 |
| 数据集规模 | 4526 个样本（走 37.2%、跑 29.2%、上楼梯 12.0%、下楼梯 10.2%、坐 6.4%、站 5.0%） |

### 1.2 主要结论

- 总体准确率：**MLP 91.7% > J48 85.1% > 逻辑回归 78.1%**，straw man 基线只有 37.2%；
  没有哪种算法在所有类别上都最好。
- **楼梯是最难的两类**：上楼梯 59.3%（J48）/61.5%（MLP），下楼梯 55.5%（J48）/44.3%（MLP）；
  作者明确指出错误主要来自**上楼梯与下楼梯互相混淆**，其次是和"走路"混淆。
- 把上/下楼梯**合并成一类**后，J48 在该类的准确率升到 **77.6%**，但楼梯仍是"最难识别的活动"。
- 坐与站虽然样本很少，仍能较好地识别（95.7%/93.3% J48）：因为两种姿态会改变设备相对重力的朝向，
  这种差异"很容易从加速度数据里看出来"；作者认为这暗示可以做姿态补偿。

### 1.3 与本实验的联系

- **窗口**：他们用 10 s / 20 Hz 的窗；我们用 **4 s / 115 Hz**。我们的采样率高一个数量级，
  4 s 窗内约有 7 个完整步态周期，正好对应他们"窗内要包含若干次重复动作"的理由；
  而 D06 实验证明窗长再缩短会放大方差与过零率抖动，再拉长则钝化方差并抬高峰值。
- **特征**：他们的 Standard Deviation / Time Between Peaks / Binned Distribution
  分别对应我们手工特征里的**方差**、**峰间距法步频**和**分位与计数族**特征。
  我们跑 TSFresh 自动特征时，SHAP top-20 里"计数与分位族"占 4 个、极值族占 4 个，
  与他们手工设计的这几族高度重合——自动化特征并没有找到"另一套物理量"，而是重新发现了同一批。
- **分类器**：他们用 J48/逻辑回归/MLP + 10 折 CV。我们用 XGBoost，但**没有用随机 10 折**：
  我们的窗口有 50% 重叠，相邻窗口共享 2 s 数据，随机折会把同一段数据同时放进训练与验证集，
  因此改用"按状态区间分组 + 切口两侧丢保护带"的划分，并程序化校验
  训练/验证窗口零重叠（`overlapping_window_pairs = 0`）。
- **评价方式**：他们用 straw man 基线应对类别不平衡；我们则同时给出 macro-F1 与每类 P/R/F1。
  实践下来这条经验很关键：当"静止"只剩 2 个测试窗口时，macro-F1 会被这一类完全带偏
  （详见第 3 节的对照结果）。
- **可复现的对照**：他们观察到"上/下楼梯互相混淆、合并后反而变好"。
  我们在自己的 21.2 分钟数据上复现了同一现象：合并后楼梯 F1 = **0.889**；
  拆成上/下两类后单类 F1 达 **0.933 / 1.000**，但整体 macro-F1 反而降到 **0.77**，
  原因是"静止"只剩 2 个测试窗口、F1 恒为 0 —— 这正是 Bulling 等人警告的
  "类别不平衡时不要只看一个总体数字"。

## 2. Bulling, Blanke & Schiele (2014)：穿戴惯性传感器 HAR 教程

> A. Bulling, U. Blanke, B. Schiele. *A tutorial on human activity recognition using
> body-worn inertial sensors.* ACM Computing Surveys, 46(3), Article 33: 1–33, 2014.
> DOI: [10.1145/2499621](https://doi.org/10.1145/2499621)

### 2.1 方法框架：活动识别链（ARC）

教程把 HAR 系统拆成一条五阶段流水线，再加一个评估环节：

1. **传感器数据采集与预处理**（去噪、标定、重采样、时间对齐）；
2. **数据分段**：滑窗、能量分段、静止位置分段，或借其它模态/外部上下文分段。
   滑窗是"对时间序列类型与结构不可知"的通用做法，但**窗长直接决定识别延迟**，
   步长则在分段精度与计算量之间折中；最佳窗长并不先验可知；
3. **特征提取与选择**：信号级（均值、方差、峰度等统计量）、人体模型级、事件级、多层级；
   特征维度越高越需要更多训练数据、算力与内存，因此要"在达到目标性能前提下用最少的特征"，
   自动排序/选择分 wrapper、filter、hybrid 三类，SVM 与 AdaBoost 自带内建选择机制；
4. **训练与分类**：模板匹配（DTW、字符串匹配）、时序概率模型（HMM、CRF、动态贝叶斯网）、
   判别式方法（SVM、C4.5、boosting）等；
5. **决策融合**：融合多传感器/多分类器的输出；
6. **性能评估**：混淆矩阵、precision/recall/F1、ROC 与 PR 曲线、AUC、EER。

### 2.2 三大研究挑战

- **类内差异（intraclass variability）**：同一活动不同人做、或同一人在疲劳/情绪/环境下做得不一样。
  按人训练（person-dependent）性能明显高于跨人（person-independent）；
  跨人时要么加数据，要么改用对人体差异更鲁棒的特征（如全身模型特征）。
- **类间相似（interclass similarity）**：物理上不同、但传感器数据极为相似的活动（如"喝咖啡"与"喝水"），
  往往只能靠**额外模态**或**共现活动**来区分。
- **NULL 类问题**：连续流里大部分数据与目标活动无关；NULL 类无法显式建模，
  可以在**方差等特征上设阈值**，或对分类器置信度设阈值来隐式识别。

### 2.3 关键实验结论

| 维度 | 结论 |
|---|---|
| 特征类型 | **均值 + 方差表现最好**；把 FFT 与过零率加进去后性能**略微下降**（k-NN 对特征质量敏感，低质量特征会拖后腿） |
| 窗口大小 | 扫 `0.1 / 0.25 / 0.5 / 1 / 2 / 3 / 4 / 5 / 6 / 7 / 8 s`：**precision 在 1 s 达到峰值**，而 **recall 随窗长增加而下降**；教程最终固定 `Ws = 1 s` |
| 传感器位置 | 单手（hand）最好：87.2% precision / 55.1% recall；多位置融合可提到 94.1% / 62.4%（按人评估）；上臂最差（30.2% / 11.4%） |
| 跨人评估 | 明显更难：全传感器组合只有 63% precision / 39.5% recall |
| 传感器模态 | **加速度计明显优于陀螺仪**；两者结合在部分位置还能再提升约 14% |
| 分类器 | 按人评估 SVM 最好（96% / 84.8%），朴素贝叶斯最差（78.2% / 69.2%），k-NN 召回最低（94.1% / 62.4%）；跨人评估下结论不明确 |
| 特征选择 | mRMR 在 `S = 150` 时最好；但某些条件下"只用均值+方差"反而更高 |
| 评估 | 类别不平衡时**总体准确率会被主导类带偏**，应改用**归一化混淆矩阵**；检测任务（含 NULL 类）更适合 PR 曲线而非 ROC |

### 2.4 与本实验的联系

- **窗口**：教程"窗长增大→召回下降、precision 在 1 s 峰值"的结论，与我们对 D06 的实测一致
  （`W = 0.25 s` 时方差标准差 4.67，是 `W = 16 s` 的 1.7 倍；`W` 拉长则方差钝化、峰值被抬高）。
  我们最终选 `W = 4 s`，是因为 115 Hz 下的 4 s 窗能容纳约 7 个步态周期，
  且 FFT 分辨率 `Δf = 1/W = 0.25 Hz` 足以分辨步频带内的主要成分。
- **特征**：教程"均值+方差最好、继续加特征可能变差"的结论，解释了我们两个看似矛盾的结果——
  只有 45 维的手工特征（含四件套 + 频域）就能到 macro-F1 0.91；
  而 2936 维的全自动特征并不比 SHAP 选出的 20 维更好（详见第 3 节），
  说明**维度不是越多越好，关键是特征质量与选择**。
- **评估协议**：教程反复强调评估阶段要与前面的设计决策联合考虑。我们把这条落实为：
  不用随机折，而是按状态区间分组 + 保护带切分，再用 `check_no_overlap` 程序化校验零重叠。
- **挑战映射**：我们把教程列出的挑战在**自己的数据上各找到一个实例**——
  "类间相似"对应上楼梯 / 下楼梯（模型跨方向无法泛化）；
  "NULL 类问题"对应我们未标注的"过渡"段（88.8 s，占全长 7%）——
  我们不去猜它的标签，而是显式标记为 `过渡` 并在训练中排除；
  "类内差异 / 跨人"对应我们提出的局限：所有数据来自同一人、同一持握方式，
  因此本实验的指标本质上是 **person-dependent** 的，不能直接与跨人结果比较。

## 3. 两篇论文与本实验关键数字对照

| 维度 | Kwapisz 2011 | Bulling 2014 | 本实验（`20261012_114607_166`） |
|---|---|---|---|
| 采样率 | 20 Hz | 综述范围内 | **115 Hz**（陀螺 46 Hz） |
| 窗长 | 10 s | 建议 1 s（扫 0.1–8 s） | **4 s**，步进 2 s（50% 重叠） |
| 特征 | 43 个手工特征（6 族） | 均值+方差最好 | 45 维手工 → **2936 维 TSFresh → top-20** |
| 分类器 | J48 / 逻辑回归 / MLP | SVM / NB / k-NN / HMM / JB | **XGBoost**（类别平衡加权） |
| 划分 | 10 折 CV | 按人/按重复留一 | **按状态区间分组 + 4 s 保护带（零重叠）** |
| 最难类 | 上/下楼梯（44.3%–61.5%） | 跨人场景 | 上/下楼梯跨方向（留一区段 `recall = 0`） |
| 类别不平衡 | 用 straw man 基线对照 | 用归一化混淆矩阵 | macro-F1 + 每类 P/R/F1，并标注小样本类 |
