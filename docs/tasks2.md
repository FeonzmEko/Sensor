# 第 2 课时 · 特征工程任务清单

> 来源：《多元感知融合 · 第 2 课时 特征工程》第 5、13、37、46 页。
>
> 主链：`乱麻 → 窗口 → 特征 → 主峰 → 步频`。保底要求是“自己采 20 分钟 + 手写时域四件套 + FFT 主峰步频”；进阶加分要求是“TSFresh + XGBoost 流水线”。
>
> 状态说明：`[x]` 表示当前仓库中已有明确证据；`[ ]` 表示尚未完成或尚未归档。当前仓库已有双传感器原始采集 App 和 62.5 秒短测，但该短测不能替代本次要求的 20 分钟日常路线数据。

## 1. 采集一条 20 分钟日常路线

- [x] **复用已跑通的采集能力**
  - [x] 应用可同步注册加速度计与陀螺仪，并保留原始 `SensorEvent.timestamp`。
  - [x] 每次采集生成独立会话目录，输出 `accelerometer.csv`、`gyroscope.csv` 和 `metadata.json`。
  - [x] 已完成 62.5 秒真机短测，证明采集、落盘和导出链路可运行。
- [ ] **确定本次实验路线与粗标签**
  - [ ] 选择一条约 20 分钟的日常路线，例如上课路、食堂路或回宿舍路。
  - [ ] 尽量混合步行、乘车、静止、电梯等至少 3 种状态，使数据具备可分性。
  - [ ] 记录手机放置位置与朝向，例如兜里、手持、腰包或车内充电台。
  - [ ] 记录 2～3 个关键时间点作为粗标签，例如上车、下车、进楼、到达。
- [ ] **一口气完成 20 分钟采集**
  - [ ] 采集前检查电量、存储空间、系统时间和页面前台状态。
  - [ ] 点击开始后连续采集至少 20 分钟，不退出应用、不熄屏、不切换应用。
  - [ ] 采集过程中不改变手机位置和朝向，不中断、不分段拼接。
  - [ ] 停止后立即确认两个 CSV 均非空，元数据状态正常，并记录停止时间。
- [ ] **检查并归档原始数据**
  - [ ] 分别统计加计与陀螺的样本数、有效时长和实测频率。
  - [ ] 检查时间戳严格递增，统计重复值、回退值和长间断。
  - [ ] 抽查加计量级为 `m/s²`，静止合加速度接近 `9.81 m/s²`。
  - [ ] 抽查陀螺量级为 `rad/s`，静止时接近 `0 rad/s`。
  - [ ] 原始 CSV 不覆盖、不修改；质量检查脚本和派生特征另存。
  - [ ] 备份原始数据到至少两个位置，并计算归档包的 SHA-256。

## 2. 滑动窗口与特征表

- [ ] **把连续数据切成可统计的窗口**
  - [ ] 以 2～4 秒为窗长候选，以约 50% 重叠为首选工作点。
  - [ ] 明确记录窗长 `W`、步进 `S`、重叠率和实际窗口数量。
  - [ ] 每个窗口保留起止时间、对应粗标签和原始数据范围。
  - [ ] 比较“全段统计”和“分窗统计”，说明为什么全段均值会混合多种状态。
- [ ] **手写时域四件套**
  - [ ] 均值 `mean`：计算每窗总体水平，并说明它主要反映重力与姿态。
  - [ ] 方差 `var`：计算每窗波动程度，用静止与步行段验证“动没动”的判别力。
  - [ ] 过零率 `ZCR`：对单轴信号去均值后统计穿越零线次数，并记录是否做带限处理。
  - [ ] 峰值 `peak`：统计每窗最大冲击或绝对峰值，并说明它对异常磕碰的敏感性。
  - [ ] 输出窗口级特征表，至少包含窗口编号、起止时间、状态标签和四类特征。
- [ ] **验证特征的分工与局限**
  - [ ] 至少选择静止、慢走、快走等 2～3 段数据对比四件套。
  - [ ] 制作用于说明“动没动、动多快、动多大”的敏感度矩阵。
  - [ ] 说明均值对运动强度基本失明、过零率可能被噪声污染、峰值可能被假冲击抬高。
  - [ ] 用一段时域特征相近但节奏不同的数据，说明四件套为什么仍需要频域补充。

## 3. FFT 主峰与步频

- [ ] **对每个分析窗口做频域变换**
  - [ ] 选择加计合矢量或合适的单轴分量，先去除直流分量。
  - [ ] 根据采样率 `fs` 和窗内样本数 `N` 计算频率分辨率 `Δf = fs / N = 1 / W`。
  - [ ] 画出 `0～fs/2` 的单边频谱，并标出奈奎斯特范围。
  - [ ] 如使用汉宁窗等窗函数，明确记录窗函数类型及其对幅值和峰形的影响。
- [ ] **读取主峰并换算步频**
  - [ ] 找到频谱最高峰对应的频率 `f_peak`，将其解释为该窗口的主要节奏。
  - [ ] 用 `步频 = f_peak × 60` 换算为“步/分钟”。
  - [ ] 将 FFT 主峰步频与峰间距法结果对比，解释频率分辨率和格点带来的差异。
  - [ ] 至少给出一段慢走、一段快走的时域/频域双联图。
- [ ] **形成可解释的完整链路**
  - [ ] 用同一段数据复现：原始波形 → 滑窗 → FFT → 主峰读数 → 步频。
  - [ ] 在报告中写明窗长、采样率、频谱范围、主峰位置和最终步频。
  - [ ] 检查主峰是否落在行人步频带 `0.5～3 Hz`，异常时回溯采样率和窗长。

## 4. 作业①：D06、D07 失效实验

- [ ] **D06 参数实验场**
  - [ ] 固定数据，只调整窗长与重叠率，观察均值、方差、过零率和峰值如何变化。
  - [ ] 将窗长推到极短端，记录方差抖动、过零率粒度和噪声影响。
  - [ ] 将窗长推到极长端，记录方差钝化、峰值升高等响应滞后问题。
  - [ ] 将步进推到 `S = W`，记录跨窗事件被劈开或漏检的情况。
  - [ ] 将步进改回约 50% 重叠，验证短事件能够被完整窗口覆盖。
  - [ ] 逐题回答 D06 页面提问，并截取至少一组失效状态和恢复后的截图。
- [ ] **D07 FFT 频谱与主频检测**
  - [ ] 依次设置 `fs = 50 → 5 → 3 → 2 Hz`，记录每一步主峰频率和频谱形态。
  - [ ] 判断主峰从哪一步开始发生“折返”，并说明它与奈奎斯特频率的关系。
  - [ ] 在 `fs = 2 Hz` 条件下找到 `1.2 Hz` 的假峰，对应 `2.8 Hz` 快踏频率的混叠结果。
  - [ ] 按“现象 → 指标 → 谱 → 采样率”的顺序复现“3000 步只计 1500”的失效链。
  - [ ] 逐题回答 D07 页面提问，并截取关键频率设置下的频谱截图。

## 5. 作业②：防止“坐公交也计步”

- [ ] **提出两个可计算、可验证的特征**
  - [ ] 候选方向一：步频带能量占比，比较 `0.5～3 Hz` 内周期性能量与传统公交车振动能量。
  - [ ] 候选方向二：主峰稳定度或峰间隔规律性，例如峰间隔变异系数、自相关峰值或主峰持续占比。
  - [ ] 对每个特征写明定义、计算方式、阈值思路以及它为什么能区分步行和乘车。
  - [ ] 选取自己的步行段与乘车站段，绘制特征分布或给出对比表。
  - [ ] 给出最终判据，说明仅凭“加速度大”“方差大”为什么仍可能误判。
