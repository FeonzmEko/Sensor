## 4. 手写时域四件套

- 均值 `mean = (1/N) Σ x_i`，主要反映重力与姿态；
- 方差 `var = (1/N) Σ (x_i - mean)^2`（总体方差，`ddof=0`），反映波动强度；
- 过零率：去均值后统计符号变化次数，`ZCR = 过零次数 / 时长`，可选 FFT 带限；
- 峰值：`peak_dynamic = max|x_i - mean|`（动态峰值），同时保留 `peak_raw`。

- 合矢量方差：min=0.016，median=9.232，max=42.240
- 全段动态峰值最大：56.505 m/s²
- 敏感度矩阵结论：方差用于“动没动”，ZCR/主峰用于“动多快”，峰值用于“动多大”。

### 8.3 为什么不能只看“加速度大 / 方差大”

- 只用方差的对照基线（阈值取步行与车辆振动方差中位数的中点，`10.12 m²/s⁴`）：真实步行窗口只有 **51.01%** 被判为步行，而仿真乘车窗口有 **41.03%** 被判为步行——方差既漏掉近一半真实步行，又把车辆整体振动误判成走路，双向都不可用。
- 更直观的例子是骑行段：动态峰值 11.09 m/s² > 步行段 8.50 m/s²，“动得更大”反而发生在不该计步的活动上。

### 8.4 结论与局限

- 结论：`R`（步频带能量占比）负责“能量在不在步频带里”，`CV`（峰间隔变异系数）负责“节奏稳不稳”，两者结合才能既保住步行、又压住乘车。
- 本次已用**真实地铁**行驶段（304 窗）替代仿真参考信号完成验证；同类活动里最容易失效的是骑行段（见 8.2）。
- 局限：`CV` 在几乎没有周期性结构的段（如电梯、静止）会因找不到足够峰而退化，此时判据实际只由 `R` 决定；真实乘车样本仅来自一条地铁线路，不同车型/线路的振动谱可能不同，阈值仍建议按线路复标。
