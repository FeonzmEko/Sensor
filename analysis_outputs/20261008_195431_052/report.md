## 4. 手写时域四件套

- 均值 `mean = (1/N) Σ x_i`，主要反映重力与姿态；

## 8. 作业②：公交防误计步

- 特征 1：步频带能量占比 `R = P(0.5~3 Hz) / P(0.5~10 Hz)`；步行段中位数 0.860，仿真车辆振动参考中位数 0.019。
- 特征 2：峰间隔变异系数 `CV = std(步间隔) / mean(步间隔)`；步行段均值 0.059，仿真车辆振动参考均值 0.288。
- 阈值思路：`R ≥ 0.5` 且 `CV ≤ 0.35` 判为步行。
- 双特征判定：真实步行段（284 窗，来自本会话打点标签）被判为步行的比例 100.00%；仿真车辆振动参考被判为步行的比例 0.00%。
- 只用方差的对照基线（阈值取步行与乘车方差中位数的中点，`8.29 m²/s⁴`）：真实步行窗口只有 12.32% 被判为步行，而仿真乘车窗口有 100.00% 被判为步行——方差既漏掉大量真实步行，又把乘车整体误判，双向都不可用。
- 结论：必须结合步频带能量占比与节奏规律性，才能抑制公交误计步。
- 注意：车辆振动仍使用仿真参考信号；本次会话采集的是步行 / 楼梯 / 电梯 / 骑行，没有真实乘车段，故“防公交误计步”的阈值仍需在含真实乘车段的会话上复标。
