## 4. 手写时域四件套

- 均值 `mean = (1/N) Σ x_i`，主要反映重力与姿态；
- 方差 `var = (1/N) Σ (x_i - mean)^2`（总体方差，`ddof=0`），反映波动强度；
- 过零率：去均值后统计符号变化次数，`ZCR = 过零次数 / 时长`，可选 FFT 带限；
- 峰值：`peak_dynamic = max|x_i - mean|`（动态峰值），同时保留 `peak_raw`。

- 合矢量方差：min=0.000，median=0.000，max=0.000

- 敏感度矩阵结论：方差用于“动没动”，ZCR/主峰用于“动多快”，峰值用于“动多大”。

## 8. 作业②：公交防误计步

- 特征 1：步频带能量占比 R=P(0.5~3)/P(0.5~10)；步行中位数 0.314，乘车参考中位数 0.021。
- 特征 2：峰间隔变异系数 CV=std/mean；步行均值 0.233，乘车参考均值 0.150。
- 阈值思路：R ≥ 0.5 且 CV ≤ 0.35 判为步行。
- 双特征判定：真实步行窗口被判为步行的比例 0.00%；仿真乘车参考被判为步行的比例 0.00%。
- 只用方差的对照基线（阈值 5.03）：仿真乘车窗口被判为步行的比例高达 100.00%，说明“加速度大/方差大”无法区分乘车与步行。
- 结论：必须结合步频带能量占比与节奏规律性，才能抑制公交误计步。
- 注意：乘车段当前使用仿真车辆振动参考信号验证管道，真实乘车特征需在 20 分钟路线数据补齐后复算。
